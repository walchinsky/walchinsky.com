# Projects

## TapOut

[TapOut](https://play.google.com/store/apps/details?id=com.galynte.tapblok) is an Android app for screen time. A focus session does not end from a button on the phone. You scan an NFC tag or a QR code you have put somewhere else, so stopping takes a real trip across the room.

Galynte publishes TapOut. The app is based on [TapBlok](https://github.com/cajdata/TapBlok) by cajdata, licensed under the Apache License 2.0.

Support mail for the app is [dev@galynte.com](mailto:dev@galynte.com).
